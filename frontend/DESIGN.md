# Design guide

The UI is built on **shadcn/ui** (Radix primitives + Tailwind v4). A calm, light interface with a **soft blue** accent from the logo's family (a pastel-blue orb); subtle motion. Check every screen in light and dark.

## Building blocks

| Need | Use |
|---|---|
| Buttons | `components/ui/button`: `default` (primary action, one per area), `outline` (secondary), `ghost` (toolbars, rows), `link` (inline). Dense areas use `size="sm"`; icon buttons use `size="icon-sm"` inside a `Tooltip`, and always have an `aria-label`. |
| Status and labels | `Badge` (`secondary` for neutral, `outline` for quiet). The semantic colours are `bg-ins text-ins-fg` (good/added), `bg-del text-del-fg` (bad/removed) and `bg-warn text-warn-fg` (attention). |
| Switching views | `Tabs` |
| Menus, overflow (⋯), "Rewrite ▾" | `DropdownMenu` |
| Small editors anchored to something | `Popover` |
| Dialogs | `components/settings/Modal` (Radix Dialog). Pickers and popovers work inside it. |
| On/off | `Switch` |
| Choosing one of a few | `ToggleGroup` |
| Choosing one of many | `Select` |
| Search palettes | `Command` (cmdk) inside a `Dialog` (⌘K) |
| Hints | `Tooltip`. Don't use `title=` on icon buttons; `title` is fine for truncated text. |
| Loading | `Skeleton` (shape of the content); `Loader2` spinning for actions |
| Transient confirmation | `toast` from `sonner` (the `Toaster` is in `components/shell/Providers.tsx`) |
| Narrow screens | `Sheet` for side panels |
| Model logos | `components/settings/ModelLogo` (`ModelLogo`, `ServerBadge`) |
| Model + reasoning pickers | `components/settings/ModelChoices` (`ModelSelect`, `EffortToggle`, `choiceLabel`, `effectiveEffort`, `useModelCatalog`) |
| Markdown | `components/document/Markdown` (`inline` for one-line context, `highlight` to mark terms); diffs: `components/document/RichDiff` (rendered) or `Diff`'s `DiffText` (raw) |
| Merging class names | `import { cn } from "cn"` |

`components/ui/*` is generated by the shadcn CLI. Don't restyle a component inside it. Pass a `className`, or wrap it.

## Tokens

Use only these (light and dark come with them). Never write raw colours.

- **Surfaces:** `bg-background` (page), `bg-card` (panels, cards, inputs), `bg-popover`, `bg-muted` (quiet fills), `bg-sidebar`
- **Text:** `text-foreground`, `text-muted-foreground` (secondary), `text-primary` (links and the accent)
- **Accent:** `bg-primary text-primary-foreground` (primary buttons), `bg-primary-soft` (selected rows, chips, highlights), `ring-ring`, `border-primary/40`
- **Hover:** `hover:bg-accent` (shadcn's meaning of *accent*: a hover background, not the brand colour)
- **Lines:** `border-border`, `border-input` (fields)
- **States:** `ins` / `del` / `warn` with their `-fg`; `destructive` for destructive buttons

## Type, spacing, shape

- **Page or area title:** `text-base font-semibold tracking-tight`
- **Section heading:** `text-sm font-medium`
- **Body:** `text-sm`
- **Meta:** `text-xs text-muted-foreground`
- **Micro labels:** `text-[11px]`; uppercase only for tiny section labels (`text-[10px] font-semibold tracking-wider uppercase`)
- **Numbers:** `tabular-nums`
- **Spacing:** a 4 px grid. Panels use `px-4 py-3`, cards `p-3`/`p-4`, groups `gap-2`/`gap-3`, sections `space-y-4`/`space-y-6`.
- **Radius:**
  - `rounded-md`: controls
  - `rounded-lg`: cards and rows
  - `rounded-xl`: panels and dialogs
  - `rounded-full`: chips, pills and avatars
- **Elevation:** `shadow-xs` on cards, `shadow-sm` on floating bars, `shadow-lg` only on popovers and dialogs (which already have it).

## Motion (`motion/react`, presets in `lib/motion.ts`)

- **New items** (chat messages, cards, list rows): `<motion.div {...rise}>` inside `<AnimatePresence initial={false}>`.
- **Things appearing at a point** (floating toolbars): `pop`.
- **Content swaps:** `fade`.
- **Resizing panels, reordering:** `layout` with `transition={spring}`.
- **Radix overlays** (popover, dropdown, dialog, tooltip) animate themselves with `data-[state]` classes. Don't wrap them.
- Keep it subtle: under 250 ms, no bounce on content, nothing that loops except progress and the logo. `MotionConfig reducedMotion="user"` turns motion off for people who ask.

## Layout

- **App shell:** the sidebar is `w-64` and collapses to a `w-12` rail with ⌘\\. It holds the search, the Documents / Projects tabs and Settings. The main area sits beside it.
- **An open document:** a top bar with the AI title, the file name, status and actions. Below it, the chat sits on the left and the document panel on the right (resizable; the panel can widen).
- **Empty states** say what to do next, with one primary action.

## Accessibility

- Every interactive element is reachable by keyboard and has a visible `focus-visible` ring (shadcn gives one).
- Icon-only buttons have an `aria-label`.
- Don't use `window.alert`, `confirm` or `prompt`. Ask inline, or in a `Modal`.
- Contrast: body text on its surface ≥ 4.5:1 (the tokens are checked for this).
